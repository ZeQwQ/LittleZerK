# 对话记录：ToDoList 任务清单功能

**日期:** 2026-10-06 15:00
**项目:** openharness-agent-loop
**主题:** 添加 ToDoList 任务清单功能

---

## 需求

用户要求给小小泽添加一个任务清单模块：
1. 小小泽每次开始工作前都要通过 ToDoList 工具创建一个"任务清单"
2. 一步一步列出任务到清单中
3. 然后根据清单中的工作规划进行思考
4. 清单只保存在内存中
5. 用户不可以中途修改清单内容
6. 清单完成后由主模型判断是否可以回答用户的问题，如果可以回答则停止

## 实现内容

### 1. 新增 ToDoList 类

```python
class ToDoList:
    """任务清单：工作前必须创建任务清单，一步一步执行"""

    def __init__(self):
        self.tasks = []       # 任务列表
        self.completed = []   # 已完成任务
        self.current_index = 0
        self.is_active = False

    def create(self, tasks: list[str]) -> str:
        """创建任务清单"""
        if not tasks:
            return "❌ 任务清单不能为空"
        self.tasks = tasks
        self.completed = []
        self.current_index = 0
        self.is_active = True
        # 返回格式化清单
        ...

    def get_current_task(self) -> str | None:
        """获取当前任务"""

    def complete_task(self, result: str = "") -> str:
        """标记当前任务完成，返回下一个任务"""

    def get_status(self) -> str:
        """获取清单状态"""

    def is_complete(self) -> bool:
        """检查清单是否全部完成"""

    def reset(self):
        """重置清单"""
```

### 2. 新增两个工具

| 工具 | 功能 |
|------|------|
| `create_todo_list` | 创建任务清单，列出解决步骤 |
| `complete_task` | 标记当前任务完成，获取下一个任务 |

### 3. 修改系统提示词

添加 ToDoList 使用流程规则：
1. 收到问题后先创建清单
2. 清单要一步一步列出解决步骤
3. 创建清单后按顺序执行每个任务
4. 每完成一个任务调用 complete_task
5. 所有任务完成后主模型判断是否可以回答

### 4. 修改 run_loop

初始化 todo_list 实例，clear 命令也重置 todo_list
